# VINCodee

Python-проект для обработки VIN-запросов и получения данных об автомобилях и автозапчастях через внешние API.

> **Статус:** pet-проект / ранний прототип. Репозиторий не развивается активно, но демонстрирует работу с HTTP API, обработкой JSON-ответов и логикой поиска деталей.

## Задача

При работе с автозапчастями данные об автомобиле и совместимых деталях часто нужно собирать из нескольких источников. VINCodee помогает автоматизировать этот процесс: принимает VIN или параметры автомобиля, выполняет запросы к внешнему сервису и приводит полученный ответ к удобному виду для дальнейшего поиска деталей.

## Возможности

- обработка VIN-запросов;
- запрос данных через внешнее API;
- разбор и нормализация JSON-ответов;
- подготовка данных для поиска деталей и кросс-номеров;
- разделение логики работы с API и обработки результатов;
- тестовые сценарии для проверки основной логики.

## Стек

- Python
- HTTP API
- JSON
- `requests`
- обработка и преобразование данных
- базовое тестирование

## Структура проекта

```text
vincodee/
├── parts/                 # Логика работы с данными о деталях
├── sevices/               # Сервисы и интеграции с API
├── tests/                 # Тестовые сценарии
├── parts_resolver.py      # Обработка и поиск деталей
├── partsapi_service.py    # Клиент внешнего API
├── test_vin_bot.py        # Тестовый запуск / проверка сценария
└── requirements.txt       # Зависимости проекта
```

> В текущей версии папка `sevices` названа с опечаткой. При дальнейшем развитии проекта её стоит переименовать в `services`.

## Запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yatochkaa/vincodee.git
cd vincodee

# Создайте и активируйте виртуальное окружение
python -m venv .venv
source .venv/bin/activate

# Windows
# .venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt

# Запустите тестовый сценарий
python test_vin_bot.py
```

## Настройка

Для работы с внешним API могут потребоваться ключи доступа. Не добавляйте их в репозиторий: храните значения в `.env` или переменных окружения.

Пример:

```env
PARTS_API_KEY=your_api_key
```

Добавьте в `.gitignore`:

```gitignore
.env
__pycache__/
*.pyc
cache.json
```
